# Pantrio — frontend

React + Vite + Tailwind frontend for Pantrio. See the [root README](../README.md) for full setup instructions covering both the backend and this frontend.

Quick start:

```bash
npm install
npm run dev
```

Requires the FastAPI backend running at the URL configured in `.env` (`VITE_API_URL`, defaults to `http://127.0.0.1:8000`).
